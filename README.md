# IntentPlayer

IntentPlayer は、MacroDroid・Tasker・Automate などからブロードキャスト・インテントで操作できる Android 向け音声プレイヤーです。通常の画面操作に加えて、フォルダ単位のキュー、バックグラウンド再生、Bluetooth連動、独自音量、再生速度変更、通知操作を自動化できます。

## 主な機能

- `再生 / キュー / フォルダ / 設定` の4タブUI
- 内部ストレージ・SDカードをファイルマネージャー形式で閲覧
- `MANAGE_EXTERNAL_STORAGE` が使えない場所では SAF（Storage Access Framework）へフォールバック
- フォルダを「選択」するとキューを構築し、自動再生はしない
- バックグラウンド再生と常駐通知
- 通知から開いた場合は必ず「再生」タブを表示
- 再生速度 `0.50x〜5.00x`、`0.25x`刻み
- 現在ファイルとキュー全体の速度反映済み残り時間表示
- IntentPlayer独自音量 `0〜500%`（100%超は増幅のため歪む場合あり）
- Bluetooth / 有線機器の切断・再接続に合わせた一時停止・自動再開
- 自動再開の有効時間 `1分〜24時間`
- Bluetooth再接続後の待ち時間 `0〜5000ms`
- 音量0時の自動一時停止と理由のトースト表示
- オーディオフォーカス送信/受信の個別制御
- Android標準MediaSessionを使わない独自再生モード
- 設定のJSONエクスポート / インポート（SAF）
- 直近エラーの確認
- Broadcast Intent による再生操作と再生イベント連携

## フォルダとストレージ

フォルダタブでは、アクセス可能な内部ストレージとSDカードを表示します。フォルダを開いて階層移動し、目的の場所で **「選択」** を押すとそのフォルダからキューを作ります。選択しただけでは再生を始めません。

Androidの権限制限やSDカード側の制約で直接読めない場合は **「SAFで開く」** を利用できます。SAFで取得した `content://` URI は、Androidが永続アクセス権を保持している間利用できます。

## 再生速度

再生速度は `0.50x` から `5.00x` まで `0.25x`刻みです。設定値は保存され、Serviceが再生成されても維持されます。通知と再生画面の残り時間も現在の速度を使って計算します。

## インテント操作

基本Actionは次の通りです。

- Action: `com.intentplayer.CONTROL`
- Target: Broadcast
- Package: `com.intentplayer` 推奨
- Extra `command` (String): 実行する操作

主な `command`:

| command | 動作 | Extra |
|---|---|---|
| `play` | 再生 / 再開 | `folderUri` (String、省略可) |
| `force_play` | 先頭から再生 | `folderUri` (String、省略可) |
| `pause` | 一時停止 | なし |
| `stop` | 停止 | なし |
| `next` | 次のファイル | なし |
| `previous` | 前のファイル / 先頭へ | なし |
| `seek` | 再生位置変更 | `seekTo` (Long、ミリ秒) |
| `speed` | 再生速度変更 | `speed` (Float、0.50〜5.00、0.25刻み) |

`play` / `force_play` で `folderUri` を省略した場合は、設定画面の **既定のフォルダ** を使用します。

詳しい MacroDroid / Tasker / Automate / ADB の例、イベント、エラー仕様は [docs/INTENT_GUIDE.md](docs/INTENT_GUIDE.md) を参照してください。

## 設定バックアップ

設定画面の **バックアップ** からJSONとしてエクスポート・インポートできます。再生位置や最近のエラーなどの一時状態はバックアップしません。

SAFの既定フォルダはAndroid側の永続アクセス権そのものをバックアップできません。そのため、インポート先端末で同じURIへの権限が残っている場合だけ既定フォルダを復元します。

## 権限

主に次の権限を利用します。

- 音声ファイル読み取り
- すべてのファイルへのアクセス（ファイルマネージャー形式の閲覧）
- 通知
- フォアグラウンドService
- Bluetooth接続情報
- バッテリー最適化除外への案内

`MANAGE_EXTERNAL_STORAGE` はGoogle Play上で用途制限のある権限です。配布方法によってはPlay Consoleで用途説明・審査が必要です。

## 再生できない場合

メディア音量が0で「音量0で一時停止する」が有効な場合、再生要求をブロックしてトーストで理由を表示します。Bluetooth再接続、自動再開、ストレージ権限、SAF権限、バッテリー最適化も確認してください。

設定画面の **最近のエラー** には、ファイル読み込みや再生失敗などの直近情報が最大20件残ります。
