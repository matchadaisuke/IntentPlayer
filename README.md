# IntentPlayer

MacroDroid 等の自動化アプリから `Broadcast Intent` を受信してバックグラウンドで音楽を再生するための、究極の自動化向け Android 音楽プレイヤーアプリです。

## 主な機能

- SAF（Storage Access Framework）によるフォルダ単位での音楽ファイル読み込み
- バックグラウンド再生（OS標準メディア通知対応 / サイレント通知の切り替え可能）
- 再生速度の変更（0.5x 〜 2.0x）
- Bluetooth / 有線イヤホンの接続・切断時の自動再生コントロール機能（トグルで無効化可能）
- MacroDroid等の外部アプリから完全にコントロール可能な Broadcast Intent インターフェース
- 状態変化（再生完了・エラー等）の Broadcast 送信による逆連携
- 初期設定を簡単に進められるオンボーディングウィザード
- トラブル時に原因を特定できる「自己診断ツール」と直近20件の「エラーログ機能」

## MacroDroid との連携ガイド

IntentPlayer の最大の特徴は、すべての操作を外部アプリから Broadcast Intent で行えることです。

### 1. 音楽を再生させる（MacroDroidからの操作）
MacroDroid の「アクション」→「インテントを送信」で以下のように設定します。

- **ターゲット**: Broadcast
- **アクション**: `com.intentplayer.CONTROL`
- **パッケージ**: `com.intentplayer` (※指定推奨)
- **Extra 1**:
  - パラメータ名: `command`
  - 種類: `String`
  - 値: `play` (前回の続きから再生) または `force_play` (最初から再生)

**その他のコマンド (command の値):**
- `pause` : 一時停止
- `stop` : 停止（再生位置リセット）
- `next` : 次の曲
- `previous` : 前の曲
- `seek` : 指定位置にシーク (Extra 2 に `seekTo` (Long) でミリ秒を指定)
- `speed` : 再生速度変更 (Extra 2 に `speed` (Float) で 0.5〜2.0 を指定)

### 2. 再生完了を検知する（MacroDroidでのトリガー）
MacroDroid の「トリガー」→「インテントを受信」で以下のように設定します。

- **アクション**: `com.intentplayer.PLAYBACK_EVENT`
- これにより、1曲終わった時やプレイリストが全て終わった時に自動でマクロを動かせます。

**Extra情報から取得できる状態:**
- `event` (String): `track_completed` (1曲完了) または `playlist_completed` (全曲完了)
- `trackName` (String): 完了した曲名

## バックグラウンド再生が勝手に止まる場合の対策

> **重要:** バックグラウンドで再生が勝手に止まる原因の多くは、スマホ本体のバッテリー最適化機能による強制終了です。

1. アプリを起動し、黄色いバナー「⚠️ バッテリー最適化が有効です」が表示されたらタップして**「最適化しない」**に設定してください。
2. Xiaomi, OPPO, VIVO 等の端末の場合は、設定アプリから「自動起動」を**オン**にしてください。

## トラブルシューティング

- **「オーディオフォーカス（Audio Focus）を奪ってしまい、裏のBGMが止まる」**
  - アプリ内の「設定」画面から「オーディオフォーカス＆標準通知」を**オフ**にしてください。これにより、他のアプリの音に干渉しない「サイレント通知モード」に切り替わります。
- **「Bluetoothの自動再開がうまくいかない / MacroDroidで制御したい」**
  - アプリ内の「設定」画面から「Bluetooth切断時の自動停止」を**オフ**にしてください。これにより、アプリ側での自動停止・再開制御が無効化され、MacroDroidなどの外部アプリから完全に制御できるようになります。
- **「どうしても再生されない・音が鳴らない」**
  - メイン画面のヘッダーにある**自己診断ツール（スパナのアイコン）**を開いてください。通知権限、ストレージ権限、バッテリー最適化など、必要な設定がすべて「許可されています」になっているか確認し、赤くなっている項目があれば「修復する」ボタンから設定を行ってください。
  - また、「設定」画面にある**エラーログ**を確認することで、ファイル読み込み失敗などの原因を特定できます。
